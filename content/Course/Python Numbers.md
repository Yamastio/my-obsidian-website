## Cue

- Apa itu variabel dalam Python?
- Apa saja tipe angka yang berbeda dalam Python?
- Bagaimana cara menginisialisasi variabel integer dan float di Python?

---

## Notes

### Variabel di Python
- **Variabel** adalah wadah yang digunakan untuk menyimpan nilai data. Mereka berfungsi untuk menyimpan, memanipulasi, dan menampilkan informasi dalam sebuah program.
- Setiap variabel memiliki **nama** yang unik dan **nilai** yang dapat memiliki berbagai tipe.
- Python secara otomatis mendeteksi tipe variabel, yang membuat proses coding lebih efisien.
- **Format Inisialisasi**: `nama_variabel = nilai`

### Tipe Angka di Python
Python mendukung beberapa tipe angka utama:
- **`int`**: Bilangan bulat, seperti `1` atau `-2`.
- **`float`**: Bilangan riil (desimal), seperti `1.32` atau `0.98`.

### Contoh Inisialisasi Variabel
- **Integer**: Menginisialisasi variabel `a` dengan nilai `3`.
  ```python
  a = 3
  ```
- **Float**: Menginisialisasi variabel `b` dengan nilai `13.2`.
  ```python
  b = 13.2
  ```

### Tantangan
- **Tingkat**: Pemula
- **Instruksi**: Tulis kode yang menginisialisasi variabel bernama `var` dengan nilai `5`.

---

## Summary

Variabel di Python berfungsi sebagai wadah untuk menyimpan nilai data, dengan Python secara otomatis mendeteksi tipenya. Tipe angka utama meliputi `int` untuk bilangan bulat dan `float` untuk bilangan desimal. Inisialisasi variabel dilakukan dengan format `nama_variabel = nilai`, memungkinkan penyimpanan dan manipulasi data yang efisien dalam program.
