## Notes

### Apa itu SDLC?
Software Development Life Cycle (SDLC) adalah sebuah proses terstruktur yang digunakan untuk membuat dan mengembangkan perangkat lunak, mulai dari perencanaan hingga pemeliharaan. Ada berbagai model metodologi yang bisa digunakan.

### 1. Model Waterfall
- **Konsep**: Metode yang sistematis dan berurutan, di mana setiap fase harus selesai sepenuhnya sebelum melanjutkan ke fase berikutnya.
- **Tahapan**: Requirement → Design → Implementasi → Testing → Verification → Maintenance.
- **Kelebihan**: Terjadwal dengan baik dan prosesnya terurut.
- **Kekurangan**: Kaku, waktu pengerjaan lama, dan tidak cocok untuk proyek kompleks yang membutuhkan fleksibilitas.

### 2. Model Prototype
- **Konsep**: Metode yang memungkinkan pengguna melihat gambaran awal (prototipe) dari perangkat lunak sebelum produk jadi dibuat, sehingga feedback bisa didapat lebih awal.
- **Tahapan**: Analisa Kebutuhan → Membuat Prototipe → Evaluasi Prototipe → Mengkodekan Sistem → Pengujian → Evaluasi → Penggunaan.
- **Kelebihan**: Pengembangan lebih cepat dan fitur lebih sesuai dengan kebutuhan pengguna.
- **Kekurangan**: Analisis dan perancangan cenderung kurang mendalam.

### 3. Model Agile
- **Konsep**: Metode yang fleksibel dan adaptif, di mana pengembangan dilakukan secara iteratif (berulang dalam siklus pendek atau *sprint*).
- **Tahapan**: Plan → Design → Develop → Test → Deploy → Review → Launch (siklus ini berulang).
- **Kelebihan**: Sangat fleksibel terhadap perubahan, pengembangan cepat, dan klien dapat terus memberikan feedback.
- **Kekurangan**: Kurang cocok untuk tim yang sangat besar dan membutuhkan kesiapan tim untuk selalu beradaptasi.

### 4. Model Fountain
- **Konsep**: Mirip dengan Waterfall, tetapi beberapa tahapan boleh tumpang tindih, dilewati, atau didahulukan.
- **Tahapan**: User Requirement → Software Requirement → System Design → Program Design → Implementation → Testing → Use → Maintenance.
- **Kelebihan**: Lebih fleksibel daripada Waterfall murni.
- **Kekurangan**: Masih relatif lebih lama dan mahal dibandingkan Agile.

---

## Summary

SDLC (Software Development Lifecycle) adalah proses pembuatan perangkat lunak yang memiliki beberapa model utama. Model Waterfall bersifat sekuensial dan kaku, cocok untuk proyek sederhana. Model Prototype fokus pada pembuatan contoh awal untuk mendapatkan feedback pengguna. Model Agile adalah pendekatan iteratif dan fleksibel yang sangat adaptif terhadap perubahan. Terakhir, model Fountain adalah variasi dari Waterfall yang memungkinkan beberapa tahapan tumpang tindih.
