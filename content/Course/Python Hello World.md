## Cue

- Apa itu Python?
- Bagaimana cara menampilkan "Hello World!" di Python?
- Apa fungsi dari fungsi `print()` di Python?

---

## Notes

### Pengenalan Python
- **Python** adalah salah satu bahasa pemrograman yang paling populer dan mudah dipelajari di dunia.
- Bahasa ini dikenal karena sintaksnya yang bersih dan mudah dibaca, membuatnya ideal untuk pemula.

### Program "Hello World!"
- Program "Hello World!" adalah program sederhana yang berfungsi untuk menampilkan teks `Hello World!` ke layar. Ini sering digunakan sebagai program pertama saat belajar bahasa pemrograman baru.
- Di Python, kita menggunakan fungsi `print()` untuk menampilkan teks ke layar. Teks yang ingin ditampilkan harus diletakkan di dalam tanda kutip (tunggal atau ganda).

- **Contoh Kode**:
  ```python
  print("Hello World!")
  ```

---

## Summary

Python adalah bahasa pemrograman populer yang mudah dipelajari. Program "Hello World!" adalah contoh dasar yang menunjukkan cara menggunakan fungsi `print()` untuk menampilkan teks ke layar. Fungsi `print()` adalah perintah fundamental di Python untuk output, dan teks yang akan dicetak harus diapit oleh tanda kutip.
