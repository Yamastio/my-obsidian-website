## Notes

### Apa itu Program Bug Bounty?
- Inisiatif di mana organisasi memberikan penghargaan kepada individu yang menemukan dan melaporkan kerentanan keamanan (bug).
- Tujuan: Meningkatkan keamanan perusahaan dan mendorong peretasan etis.

### Mengapa Perusahaan Menggunakan Bug Bounty?
- Hemat Biaya (Cost-Effective): Hanya membayar untuk bug valid.
- Bakat Global (Global Talent): Mengakses peretas etis terampil dari seluruh dunia.
- Pengujian Berkelanjutan (Continuous Testing): Pengujian keamanan 24/7.

### Siapa Saja yang Bisa Menjadi "Pemburu Bug"?
- Profesional Keamanan.
- Mahasiswa dan Pemula: Cara bagus untuk belajar sambil praktik.
- Peretas Etis: Bersemangat tentang keamanan, untuk pengakuan atau reputasi.

### Jenis Program Bug Bounty:
- Program Privat (Private): Hanya untuk peneliti yang diundang khusus.
- Program Publik (Public): Dapat diakses oleh seluruh komunitas peretasan.

### Perbedaan Bug Bounty Program (BBP) dan Vulnerability Disclosure Program (VDP):
- Vulnerability Disclosure Program (VDP): Hanya panduan cara menerima informasi kerentanan, tidak ada hadiah uang.
- Bug Bounty Program (BBP): Mendorong penemuan dan pelaporan bug, memberikan hadiah moneter.

### Pentingnya Kode Etik (Code of Conduct):
- Mematuhi kode etik/kebijakan program sangat penting.
- Menetapkan harapan perilaku dan membuat laporan lebih efektif.
- Profesionalisme dan kemampuan teknis harus seimbang.

### Struktur Program Bug Bounty (Apa yang Perlu Dibaca):
- Scope: Menentukan IP, domain, dan jenis kerentanan yang boleh diuji.
- Out of Scope: Menentukan apa yang tidak boleh diuji.
- Rewards: Menjelaskan jenis hadiah dan kriteria.
- Safe Harbor: Jaminan tidak ada tuntutan hukum jika bertindak baik.
- Rules of Engagement: Menentukan apa yang boleh/tidak boleh dilakukan.
- Reporting Format: Format spesifik untuk laporan.
- Responsible Disclosure Policy: Kebijakan tentang jadwal pengungkapan.

### Platform Bug Bounty Populer:
- HackerOne, Bugcrowd, Intigriti, YesWeHack.
- Lainnya: Synack, Hackenproof, Hackrate, Cyber Army Indonesia, Redstorm.

### Jenis Target Umum untuk Pemburu Bug:
- Aplikasi Web: XSS, SQLi, CSRF, IDOR.
- Aplikasi Seluler: API cacat, penyimpanan tidak aman, otentikasi tidak tepat.
- API (Application Programming Interfaces): Akses tidak sah, bypass batasan laju, paparan data.
- Infrastruktur: DNS, kesalahan konfigurasi cloud, port terbuka.

## Summary

Program Bug Bounty menawarkan cara yang menarik dan bermanfaat bagi siapa saja yang ingin belajar dan berkontribusi pada keamanan siber, baik untuk hobi maupun karir. Dengan memahami dasar-dasar, mengikuti kode etik, dan memanfaatkan platform yang tersedia, Anda bisa menjadi bagian dari komunitas yang membantu membuat dunia digital lebih aman dan bahkan mendapatkan penghargaan untuk upaya Anda. Ini adalah perjalanan yang sangat bagus untuk menjadi seorang Peretas Etis.
