## Notes

### Mengapa Pemrograman dan Sistem Operasi Penting

- **Manfaat Pemrograman**:
  - Mengotomatisasi tugas-tugas yang berulang dengan tingkat akurasi tinggi.
  - Mengurangi risiko kesalahan manusia dalam operasi keamanan.
  - Menghemat waktu secara signifikan dibandingkan pengerjaan manual.
- **Peran Sistem Operasi**:
  - Menyediakan antarmuka dasar untuk berinteraksi dengan komputer, seringkali melalui perintah teks.

### Linux

- **Definisi**: Sistem operasi open-source yang banyak digunakan di lingkungan server dan keamanan.
- **Ciri Khas**:
  - Menggunakan `command line` sebagai antarmuka utama, berbeda dengan GUI pada MacOS atau Windows.
- **Penggunaan dalam Keamanan Siber**:
  - Menganalisis log sistem untuk mendeteksi anomali, seperti lalu lintas jaringan yang tidak biasa.
  - Menjalankan perintah untuk memeriksa log kesalahan dan aktivitas mencurigakan.

### SQL (Structured Query Language)

- **Definisi**: Bahasa pemrograman standar untuk membuat, berinteraksi, dan mengambil data dari database relasional.
- **Fungsi**:
  - Menyaring jutaan baris data dalam database untuk mendapatkan informasi spesifik yang relevan.
- **Penting bagi Analis Keamanan**:
  - Membantu menganalisis data besar (big data) dengan efisien untuk mengidentifikasi pola ancaman.

### Python

- **Definisi**: Bahasa pemrograman tingkat tinggi yang mudah dipahami dan sangat fleksibel.
- **Fungsi dalam Keamanan Siber**:
  - Mengotomatisasi tugas-tugas keamanan yang berulang, seperti pemindaian kerentanan.
  - Melakukan proses yang membutuhkan akurasi tinggi, seperti parsing log atau analisis malware.
- **Keuntungan**:
  - Dapat digunakan untuk berbagai kebutuhan keamanan, termasuk pengolahan data, pembuatan skrip otomatis, dan pengembangan alat keamanan kustom.

### Persiapan untuk Dunia Kerja

- Alat yang digunakan di setiap organisasi mungkin berbeda-beda.
- Familiaritas dengan alat-alat standar industri menunjukkan kemampuan untuk mempelajari dan beradaptasi dengan alat baru.

### Langkah Berikutnya

- Materi mendalam tentang Linux, SQL, dan Python akan dijelaskan lebih lanjut dalam program ini.
- Terdapat latihan langsung untuk memahami penerapan alat-alat tersebut dalam skenario keamanan nyata.
